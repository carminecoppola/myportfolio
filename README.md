# Carmine Coppola — portfolio

Personal site built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 and Motion.

## Content

All text, links and downloads live in `src/data/profile.ts`. PDFs are in `public/materials/` (EASY paper, slides, poster, award) and `public/publication/` (earlier work).

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

## Notes

- Light and dark themes, saved per visitor, no flash on load.
- Animations respect `prefers-reduced-motion`.
- Open Graph image, favicon and sitemap are generated by Next (`opengraph-image.tsx`, `icon.tsx`, `sitemap.ts`).
- Update `siteUrl` in `src/app/layout.tsx`, `src/app/sitemap.ts` and `public/robots.txt` if the domain changes.

## Deploy

```bash
npx vercel
```
